# Oversight notes

Use for an explicitly requested independent, blinded or comparative assessment. Ordinary review follows [review](review.md) in the current agent. [TEAM](../../../runtime/TEAM.md#review-findings-and-independence) governs an assigned independent reviewer.

1. **Independence.** The reviewer works from a fresh context with the inputs the protocol allows; prior exposure is recorded.
2. **Observed defect and proposed cause** are recorded separately; the explanation changes when passages or calculations contradict it.
3. **Criteria before results.** Set the requested review objective before reading compared outputs. Economic reviews prioritize impact, then assumption economy, conclusion strength and economic implications using the same target and evidence; findings follow the evident-error criterion and Requested work in ECONOMIST. Choice assessments use its Selecting an action procedure for contrasting structures and a concrete adopted action. Editorial reviews also assess whether the reader recovers the question, mechanism and result.
4. **Transfer assessment.** A requested transfer evaluation freezes shared rules before designated unseen material is opened. Record prior exposure and use the authorized evaluation budget. Harness improvements use shared reasoning rules; task answers and numeric keys stay in evaluation records.
5. **Separate outcomes.** Explanation of the development case, choice in the new case and the resulting outcome are assessed separately, from actual returned calculations and artifacts.
6. **Disposition.** The coordinator integrates findings and decides; a comparison that cannot answer the question goes back to the result owner.
