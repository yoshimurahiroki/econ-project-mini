# Delegation and continuation

## Native model roles

ERS uses `gpt-6.1-sol`, reasoning `low`, for lead, implementation, retrieval, specialist, review and harness evaluation work. Explicit Luna and Astra assignments retain their configured settings. Terra roles are retired. Improvement evaluations run sequentially with concurrency one.

The lead owns the question, specification, adoption and integration. Delegate a bounded operation when its benefit exceeds coordination cost. Apply the supported model fields and the user's tighter settings. [Native limits](../docs/ai/config-templates/README.md#native-delegation-limits) govern host capacity.

## Shared work

Give each worker the original objective, owned scope, inputs, settled results, exact remaining operation and completion criterion. Use one writer per file or owned region. Workers read the current-stage procedure and reuse supplied source bodies. Preserve others' edits.

## Return and integration

Return the result, producing paths and versions, evidence and remaining dependency. The lead reconciles it with the original request and completes the integrated answer. Keep bulk artifacts in their owned paths.

## Resumption

Recover the original request, fixed inputs, completed work and next authorized action from the existing worksheet and [saved work](../harness/state.md#find-saved-work). Reuse settled content. User cancellation and pause instructions govern continuation.

## Requested usage accounting

Use actual host usage through the [usage interface](../harness/state.md#observed-execution-usage). Record requested and returned model settings, time and exposed usage fields. Compare work under the same inputs and deliverable.

## Review findings and independence

Independent review follows an explicit assignment in fresh context. Record the reviewer, scope, prior exposure and actual evidence. Economic review follows ECONOMIST Economic priority, Requested work and econ-review: highest economic impact, weakest sufficient premises, strongest derived conclusion and deep economic implications. The parent owns adoption.
